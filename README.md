# 🎓 Campus Complaint System

A simple and easy-to-use web application for students to submit, track and manage their campus complaints online.

## ✨ Features
- Student Registration & Login
- Submit New Complaint
- View My Complaints
- Edit Complaint
- Student Dashboard
- Secure Login System

## 🛠️ Technologies Used
- PHP
- MySQL
- HTML / CSS
- XAMPP (Apache Server)

## 📁 Project Files
- index.php - Home Page
- register.php - Student Registration
- login.php - Student Login
- dashboard.php - Student Dashboard
- my_complaints.php - View All Complaints
- edit_complaint.php - Edit Complaint
- db.php - Database Connection

## 🚀 How To Run This Project
1. Install XAMPP
2. Copy this project folder to `C:\xampp\htdocs\`
3. Start Apache & MySQL in XAMPP
4. Create database named `campuscare` in phpMyAdmin
5. Open browser and go to `http://localhost/campuscare`
